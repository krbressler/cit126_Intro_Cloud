What is Cloud Computing? (Module Defined)

Cloud computing is the on-demand delivery of compute power, database, storage, applications, and other IT resources via the internet with pay-as-you-go pricing.

Subject Matter Expert Nuance: In traditional models, infrastructure is treated as hardware, requiring large capital investments and capacity prediction. In the cloud model, you stop thinking of physical servers and instead treat infrastructure as software which can be automated, scaled down, or discarded dynamically.

The Six Core Advantages of Cloud Computing:

1
Trade CapEx for Variable Exp Pay only when consuming resources, scaling down upfront risk.
2
Massive Economies of Scale Aggregate usage across customers lets AWS pass price discounts down.
3
Stop Guessing Capacity Access as much as you need; scale dynamically without paying for idle assets.
4
Increase Speed & Agility Spin up databases, compute runtimes, or networks instantly in minutes.
5
Stop Running Data Centers Stop structural heavy lifting (stacking, cooling, power grid overhead).
6
Go Global in Minutes Deploy solutions cross-region to slash latency for worldwide users.

Infrastructure (IaaS) #1

Amazon EC2 instance deployment where your staff installs a custom Linux OS runtime, handles application dependencies, and patches network firewalls.

Platform (PaaS) #1

AWS Elastic Beanstalk deploys node.js applications automatically handles load balancing, capacity scaling, and monitoring without server OS administrative tasks.

Software (SaaS) #1

A company subscribes to Microsoft Office 365 or Slack. The cloud service provider runs, secures, updates, and manages all server-side functions completely.

Infrastructure (IaaS) #2

Deploying Amazon Virtual Private Cloud (VPC) subnets, custom routing rules, and allocating raw Amazon EBS storage blocks directly linked to bare instance nodes.

Platform (PaaS) #2

AWS Lambda Serverless computing: Developers write code and attach API endpoints. AWS automatically handles physical environments, operating runtimes, and compute nodes scaling.

Software (SaaS) #2

AWS Artifact: Directly downloading pre-signed compliance certificates and reports from a finished portal page without running databases or back-end runtimes.

Exploring the AWS Cloud Adoption Framework (AWS CAF)

For successful cloud adoption, an organization must align its technology, people, and processes (Page 31/32). The AWS CAF provides guidance and best practices organized into six perspectives. These are split into two focus tiers:

Focus on Business Capabilities

  • Business: Ensures IT is aligned with business needs, and investments produce demonstrable business results (IT strategy, IT finance).
  • People: Evaluates organizational structure, skill needs, career paths, and guides the change strategy.
  • Governance: Aligns IT strategy with business strategy to minimize risks and maximize cloud portfolio values.

Focus on Technical Capabilities

  • Platform: Guides detailed target state cloud environments, structural templates, and systems architecture.
  • Security: Outlines identity, access control guidelines, data protection, compliance frameworks, and incident response.
  • Operations: Defines operational governance, day-to-day service monitoring, system releases, and backup recovery actions.

Match Stakeholder Statements to AWS CAF Perspectives:

"We must prioritize training, staffing, and organizational changes to build an agile organization."
"We must ensure that skills and processes align IT investments with business strategy to minimize risks."
"We must understand and communicate the target state architecture and systems relationships."
"We must define day-to-day business monitoring, software releases, and disaster recovery rules."
